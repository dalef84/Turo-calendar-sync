# Privacy Policy **Last updated: September 23, 2026** Turo Calendar Sync ("the Extension") is a Chrome extension that synchronizes a user's Turo vehicle availability information with Google Calendar. ## Information the Extension accesses The Extension may access: - Turo vehicle calendar information, including booking and blocked time periods. - Google Calendar information necessary to create, update, and manage calendar events. - Google account authentication information provided through Google's OAuth authentication system. The Extension does not intentionally collect guest names, payment information, addresses, passwords, or other sensitive Turo information. ## How information is used Turo calendar information is used solely to create and maintain corresponding events in the user's Google Calendar. The Extension does not: - Sell or rent user information. - Use information for advertising. - Use information for creditworthiness or lending purposes. - Transfer information to data brokers. - Use Google user data for purposes unrelated to providing the Extension's calendar synchronization functionality. ## Data storage The Extension does not operate a remote server or database and does not sell or retain users' Turo or Google Calendar data on a developer-controlled server. Authentication tokens are handled through Chrome's extension authentication mechanisms and Google's OAuth system. The Extension may store local configuration information in the browser using Chrome's extension storage APIs. ## Data sharing The Extension communicates directly with Turo's services to retrieve the user's vehicle calendar information and with Google's Calendar API to synchronize calendar events. No user data is intentionally shared with third parties other than the services required to provide the Extension's functionality. ## Google API Services The Extension's use of information received from Google APIs complies with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Google's handling of account information is governed by Google's own privacy policies. ## Data security The Extension uses HTTPS connections when communicating with Turo and Google services. OAuth authentication is handled through Google's authentication mechanisms rather than by collecting or storing the user's Google password. ## User control Users can revoke the Extension's Google Calendar access through their Google Account settings and can remove the Extension from Chrome at any time. ## Changes to this policy This privacy policy may be updated when the Extension's functionality or data practices change. The updated version will be made available at the same privacy policy location. ## Contact For questions about this privacy policy or the Extension, contact the developer through the Chrome Web Store listing.
